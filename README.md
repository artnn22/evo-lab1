# Лабораторная работа № 1

Генетический алгоритм для функции Диксона—Прайса.

- Вариант: **V = 9**, размерность **d = 8**.
- Область поиска: каждая координата от **−10 до 10**.
- Алгоритм: вещественный генетический алгоритм с турнирным отбором, BLX-α, гауссовской мутацией и элитизмом.
- Эксперименты: 20 запусков на конфигурацию и случайная выборка с тем же бюджетом.

## Запуск

Все команды ниже выполняются из папки `lab1`.

Установить зависимости:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Запустить все эксперименты (по 20 запусков двух конфигураций ГА и случайного поиска):

```bash
python3 -m src.experiment
```

Настройки находятся в `configs/base.json` и `configs/sigma_large.json`. Они отличаются масштабом мутации. Число запусков задано в начале `src/experiment.py`: `RUNS = 20`.

Запустить проверки:

```bash
python3 -m tests.test_function
```

## Где искать результаты

Таблицы и графики сохраняются в `results/`. Там же уже лежат результаты серии из 20 запусков, описанной в отчёте.

- `runs_*.csv` — результат каждого отдельного запуска.
- `traj_*.csv` — изменение лучшего значения по поколениям.
- `summary.csv` — сводка: лучший, средний, медианный и худший результат.
- `convergence_base.png` — график сходимости базовой конфигурации.
- `comparison_box.png` — сравнение генетического алгоритма и случайного поиска.
